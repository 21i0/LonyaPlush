# 游戏操作

## 界面和操作

实体 Shift＋右键打开 AE 风格菜单。下方四个按钮分为两排：日常闲聊／拜访洛猫，历史回顾／回收玩偶。角色展示右上角显示当前玩家的好感度，标题从语言文件读取。外观由模组自绘，不需要安装 AE2。

## 好感度与拜访

好感度按世界和玩家 UUID 保存，初始为 0。同一玩家换玩偶、回收、重新部署或重进游戏都会保留好感度。

- 日常闲聊：点击后立即在菜单显示一条随机对白，并切换该条配置的表情；只抽取当前好感度处于其范围内的对白。首次闲聊或此前连续 60 秒未闲聊时增加 1 点，否则只聊天不加点。每次闲聊都会重新开始计算这 60 秒，不受章节冷却限制，也不改变章节阅读位置；路线结束后仍可闲聊。
- 主线选项：在对应的 `chapter1.json` 至 `chapter5.json` 中配置回答、正负好感度变化、各自对白和后续共同对白，也可在分支内继续设置选项。默认第四章保留两个回答，分别 +5／-5，其他章节维持线性对白。同一选择节点的好感度变化只在首次作答时结算，重玩仍可换路线，但不重复增减；好感度最低为 0。第四章的友善回答解锁第五章，另一回答在分支与共同对白读完后结束本次路线。
- 实体陪伴：属于自己的活动玩偶在同维度 6 格内时，累计 1200 个游戏刻（正常速度 1 分钟）增加 1 点。只计算在线、存活且非旁观模式的玩家；多只玩偶不会叠加计时，物品和方块摆件不计时。剩余陪伴进度也会保存，离线不累积。

“拜访洛猫”直接尝试打开当前主线进度，不再打开章节选择界面：未读完时继续当前章，读完后进入下一章。五章分别需要 20、40、60、80、100 点好感度，并保留章节顺序和第五章的剧情条件。好感度不足时，在菜单对白区域显示所需数值及获取方式；此提示优先于章节冷却提示。主线结束后提示前往历史回顾重玩。已读 CG、梗概与重玩入口仍在“历史回顾”中。

旧存档缺少好感度字段时从 0 开始，已有章节完成记录和阅读位置不会清空，进入章节仍需达到对应门槛。

## 阅读操作

CG 按比例裁切铺满屏幕，底部使用紧凑的半透明对话框：

- 左键、空格或 Enter：第一次显示当前全文，再次立即继续。无需等阅读计时。
- “快进”或按住 Ctrl：连续推进，到回答选项时暂停。
- “自动”：根据每条对白的文字长度自动计算停留时间，遇到选项暂停；手动和快进均不受等待限制。
- 右键或 H：隐藏／显示阅读界面；隐藏时暂停自动和快进。
- 滚轮向上、L 或“历史”：打开只读历史，默认定位最新记录；打开期间暂停打字、自动和快进，返回保留原阅读位置。
- 历史支持滚轮、拖动滚动条、PageUp／PageDown、Home／End、最早／最新以及分页按钮；Esc 或右键返回。
- “章节回顾”打开章节列表。已读章节可查看 CG 与梗概，也可从头重玩。
- 历史回顾中的第五章在第四章选择第一个回答并读完第四章后可进入；拜访按钮直接尝试继续主线。
- 第四章选择第二个回答会结束本次路线；可通过历史章节重玩第四章重新回答。

对白仅有 Lonya 与玩家，旁白用于描述场景。第五章由 Lonya 录制结束后主动打来电话，第四章也是手机语音通话。角色性格按提供的角色设定编写；现实身份补充没有写进剧情。

最近 512 条实际读过的对白按玩家保存，包含选择后的实际分支；退出界面、重新进入世界后仍可恢复，不会加入未选择的分支。节点配置了稳定 id 时，保存的阅读位置和历史可按 id 恢复；修改剧情结构时建议保留已有 id。旧存档仅能恢复原有线性阅读记录。

每章结束后默认有 20 分钟冷却，期间仍可查看历史、CG 和回收。中途退出不新增冷却，剩余时间按玩家保存在世界中，离线照常流逝。冷却配置与更多修改说明见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

闲聊与主线的 JSON 配置方法见 [剧情配置说明](STORY_FORMAT.md)。

## 赠送贵重物品

主人在自己的活动玩偶 6 格内，将以下物品主动丢到玩偶 2 格内即可送礼。玩偶每半秒检查一次，等待物品原生拾取延迟结束，并要求物品可见；只收主人丢出的物品，不收其他玩家的礼物、挖矿自然掉落或隔墙物品。

| 礼物 | 每个增加好感度 |
| --- | --- |
| 金锭 | 1 |
| 绿宝石 | 3 |
| 钻石 | 5 |
| 下界合金锭 | 10 |
| 对应金块／绿宝石块／钻石块／下界合金块 | 对应单个材料的 9 倍 |

会一次收取整组，按数量结算，并在快捷栏上方显示物品、数量与实际增加的好感度。礼物被消耗，回收玩偶不会返还；多只玩偶不会对同一掉落物重复结算。物品和方块摆件不收礼。礼物不受闲聊或章节冷却限制，好感度仍记在主人身上。物品及数值在 `LonyaGifts.java` 中定义。
