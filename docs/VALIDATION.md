# 1.1.2 验证记录

2026-10-23，1.1.2 的原定制工程实际通过：

- `compileJava -Pchecks`。
- 同一个世界连续两次 `runRegression -Pchecks`：玩偶组件、所有权、回收、活动实体、剧情和冷却时间跨服务端进程保存恢复。
- 章节冷却默认 1200 秒，开关、自定义时长、0 秒、到期前 1ms 和恰好到期、玩家隔离、换玩偶/重开界面防绕过、重复数据包、旧存档兼容。
- `runVisual -Pchecks`：22 个真实客户端场景，包含冷却倒计时、自动恢复按钮、窄窗口、章节显隐、历史暂停和返回；已检查截图。
- `runStoryServer` + `runStoryClient`：真实键鼠及网络，完整第一章结束后显示 20 分钟冷却，服务端拒绝伪造提前聊天请求，冷却中仍可查看 CG 和回收。
- 无 `-Pchecks` 的生产构建与 JAR 审计：仅 Minecraft、NeoForge 必需；Curios 可选；不包含 checks 类、原担架 Java 包或其他模组硬依赖。

本仓库来自该完整工程，保留源码、测试夹具、皮肤、眨眼帧、伞面、五章对白和 CG。为适合分享，只清理了本机绝对路径，补充仓库说明、自动构建工作流和忽略规则；Java 与对白保持不变。`dist/SHA256SUMS.txt` 记录仓库成品的校验值。

分享工程已在新目录独立执行 `gradlew.bat build --console=plain`，17 秒完成。新 JAR 与原 1.1.2 的 ZIP 条目逐项比较，唯一内容差异是 `skin.json` 的来源路径改为 `skin.png`，全部 Java 类、剧情、皮肤、CG 及其他资源一致。

构建目录、测试世界、日志、账号凭据以及独立提供的真人资料没有放进仓库。
